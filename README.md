# 🎮 Rock Paper Scissors Game in Python

A simple, interactive **Rock Paper Scissors game built using Python**. Play against the computer, which randomly selects rock, paper, or scissors in each round.

## ✨ Features

- 🎲 Random computer choices using Python's `random` module.
- 🔁 Continuous gameplay using a `while` loop.
- ✅ Input validation to ensure valid choices.
- 🏆 Automatic winner detection based on the game rules.
- 🎉 Fun console output with emojis and decorative separators.

## 🛠️ Technologies Used

- **Python 3**
- `random` module

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository or download the source code.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python main.py
   ```

   Replace `main.py` with your Python filename if it is different.

5. Enter `rock`, `paper`, or `scissor` when prompted.
6. The computer will make its choice, and the game will display the result.
